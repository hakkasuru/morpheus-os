# Knowledge base

* [Decisions](/knowledge/decisions/index.md) - durable architectural and process decisions, with rationale and consequences.
* [Runbooks](/knowledge/runbooks/index.md) - step-by-step procedures agents execute on request.
* [References](/knowledge/references/index.md) - external URLs and pointers worth remembering.
* [Notes](/knowledge/notes/index.md) - free-form observations that don't fit a decision, runbook, or reference yet.
* [Repos](/knowledge/repos/index.md) - per-repo knowledge-base sections, one subdirectory per registered repo id.
* [Bundles](/knowledge/bundles/) - vendored external knowledge bundles (gitignored; registered in config/bundles.yaml, synced by scripts/sync-bundles.sh, read-only).
